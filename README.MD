# Marp Slides

## Startup

```
make serve
# Starts a webserver on port 8080 which serves all your slides
```

> Note: All slides can be created inside the src folder. Marp only renders files with the `.md` extension.

## Generate PPTX files
```
make generate-pptx 
# creates pptx files for all the slides in src
```


## Setup

To install all dependencies run

```
make setup
```
